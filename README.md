# KhanFT-FCP-Motion-Templates
Final Cut Pro templates (effects, titles, transitions, generators) built in Apple Motion with Claude by Mehedi Hasan Khan.

This repo is the `Motion Templates.localized` folder. Only the `KhanFT` subfolder inside each template type is tracked:

- `Effects.localized/KhanFT`
- `Titles.localized/KhanFT`
- `Transitions.localized/KhanFT`
- `Generators.localized/KhanFT`
