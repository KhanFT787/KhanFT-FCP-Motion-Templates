# KhanFT-FCP-Motion-Templates
Free Final Cut Pro effects, titles and transitions built in Apple Motion with Claude by Mehedi Hasan Khan (KhanFT).

📘 **[User guide (PDF)](KhanFT-Plugins-Guide.pdf)** — what every plugin does and how to use it.

## What's inside
- **Effects:** BOX, Float, Highlight, Outline, Photo Card
- **Titles:** Text Type 1, Words Type 1, Cards Type 1–2, Section Type 1–8
- **Transitions:** Section Type 2 – Page Drop Transition

Built for 16:9 at 4K (3840×2160); also works in 1080p. Bangla-ready fonts included in the card titles.

## Install
1. Click **Code → Download ZIP** and unzip.
2. In Finder press ⇧⌘G and open `~/Movies/Motion Templates.localized` (create it if missing).
3. Copy each `KhanFT` folder into the matching folder:
   - `Effects.localized/KhanFT`
   - `Titles.localized/KhanFT`
   - `Transitions.localized/KhanFT`
4. Restart Final Cut Pro. Look for the **KhanFT** category in the Effects, Titles and Transitions browsers.

The `.py` scripts and `_build` folder in `Titles.localized/KhanFT` are build tools and aren't needed to use the plugins.
